THPT BÁ THƯỚC - WEBSITE KỶ NIỆM 60 NĂM
=============================================

Cấu trúc:
- index.html                  : trang web chính
- assets/banner.png           : banner 60 năm
- assets/danh-sach-tai-tro.png: ảnh danh sách tài trợ gốc

Cách công khai:
1. Giải nén file ZIP.
2. Đưa toàn bộ nội dung trong thư mục này lên dịch vụ hosting/static hosting.
3. File index.html phải nằm ở thư mục gốc của website.

Website không cần máy chủ/database để chạy phần tra cứu hiện tại; dữ liệu nhà tài trợ đang được lưu trực tiếp trong index.html.
